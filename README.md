# ResumeRank AI — Review 2 Frontend

This is a Streamlit frontend/demo for the project **Intelligent Resume Screening and Candidate Ranking System**.

## VS Code setup
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:
   `python -m venv venv`
4. Activate:
   `venv\Scripts\activate`
5. Install:
   `pip install -r requirements.txt`
6. Start:
   `streamlit run app.py`

Open the local address shown in the terminal, normally `http://localhost:8501`.

## Review demo
Dashboard → Screen Resumes → upload JD → upload 2–3 resumes → click Screen Resumes → show ranked scores → expand DSA analysis → open DSA Insights.

The frontend demonstrates the algorithms listed in the review document: KMP, Rabin-Karp, Dynamic Programming, sorting, Hash Table and Priority Queue.
